## Why

tokscale CLI の `--json` 出力を手動で確認して利用プランの残量を把握するのは煩雑で、リアルタイム性に欠ける。ユーザーがデスクトップ上で常時表示できる監視アプリを通じて、各ローリングウィンドウ（5時間/週間/月間）のコスト消費状況を直感的に把握できるようにし、予算超過リスクを未然に防ぐ。

## What Changes

- **Rust backend（Tauri）**: `tokscale --json --no-spinner` を実行し、標準出力をフロントエンドに返す `get_tokscale_raw_data` コマンドを追加。
- **PlanConfig の導入**: 対象モデル、各ウィンドウの上限金額を定義する拡張可能な設定オブジェクトを追加。将来的なプラン変更やモデル追加に対応。
- **ローリングウィンドウ計算ロジック**: 現在時刻を基準に 5時間/1週間/30日間のセッション cost を集計し、残予算と使用率を算出。80% 超過時の警告判定も実装。
- **Next Free Slot 予測**: 5時間ウィンドウの最も古いセッションが外れる時刻を概算し、「あと何分で枠が空くか」を表示。
- **ドーナツチャート UI**: 3 つのウィンドウ（5時間/週間/月間）を横並びで可視化。中心に残予算、使用率 80% 超で警告色へ遷移。
- **自動更新**: 60 秒ごとにバックエンドをポーリングし、表示を自動リフレッシュ。

## Capabilities

### New Capabilities
- `tokscale-data-fetch`: 外部コマンド `tokscale --json --no-spinner` を安全に実行し、その JSON 出力をフロントエンドに供給するバックエンド機能。
- `plan-limit-monitor`: 取得した JSON データを PlanConfig に基づいてフィルタリング・集計し、ローリングウィンドウごとの残予算・使用率・Next Free Slot を算出して可視化するフロントエンド機能。

### Modified Capabilities
- （該当なし。既存の spec はない。）

## Impact

- `src-tauri/src/lib.rs`：新規 Tauri コマンド `get_tokscale_raw_data` の追加。
- フロントエンド：PlanConfig 型定義、データフィルタリング・集計ロジック、ドーナツチャート Svelte コンポーネント、自動更新タイマーの実装。
- 依存関係：追加の外部クレートは最小限に抑える（標準ライブラリ + Tauri の `Command` API のみ使用）。
